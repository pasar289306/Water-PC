# AquaAudit – پلتفرم ممیزی و مدیریت آب صنایع (نسخه MVP)

نرم‌افزار وب فارسی (RTL) برای ثبت جریان‌های آب یک مجتمع صنعتی، محاسبه موازنه آب با عدم قطعیت، شاخص‌های عملکرد (KPI)،
مدل‌های تجهیزات، بانک راهکارهای صرفه‌جویی، تحلیل اقتصادی پروژه‌ها و تولید گزارش ممیزی.
پیاده‌سازی بخش‌های «MVP» سند Methodology است (بدون هوش مصنوعی و بدون اتصال مستقیم به SCADA).

## نصب

نیازمند Python 3.11 یا بالاتر و دسترسی به اینترنت برای نصب وابستگی‌ها (pip).

**لینوکس / مک**
```bash
git clone https://github.com/pasar289306/Water-PC.git && cd Water-PC
./install.sh --run          # نصب و اجرا؛ گزینه --no-demo برای استقرار واقعی بدون داده نمونه
# بعداً:  ./start.sh
```

**ویندوز (PowerShell)**
```powershell
git clone https://github.com/pasar289306/Water-PC.git; cd Water-PC
powershell -ExecutionPolicy Bypass -File install.ps1 -Run
# بعداً:  powershell -ExecutionPolicy Bypass -File start.ps1
```

نصب‌کننده محیط مجازی `.venv` می‌سازد، وابستگی‌ها را نصب می‌کند و فایل `.env` را با `AQUA_SECRET` و گذرواژه
تصادفی مدیر (`AQUA_ADMIN_PASSWORD`) تولید می‌کند (فایل `.env` در git ذخیره نمی‌شود). سپس به
`http://127.0.0.1:8000` بروید و با کاربر `admin` وارد شوید.

> اسکریپت لینوکس/مک روی یک کپی تمیز آزمایش شده است؛ `install.ps1` در محیط ساخت (بدون ویندوز) اجرا نشده و
> در اولین استفاده روی ویندوز باید بررسی شود.

## اجرای سریع (بدون install)

```bash
./run.sh                 # ساخت venv، نصب وابستگی‌ها و اجرا روی http://127.0.0.1:8000
```

یا با Docker:

```bash
export AQUA_ADMIN_PASSWORD='یک-گذرواژه-قوی'
export AQUA_SECRET="$(openssl rand -hex 32)"
docker compose up --build
```

- در اجرای محلی، گذرواژه اولیه کاربر `admin` (اگر `AQUA_ADMIN_PASSWORD` تنظیم نشده باشد) به‌صورت تصادفی ساخته و در
  `data/INITIAL_ADMIN_PASSWORD.txt` ذخیره می‌شود. پس از ورود آن را تغییر دهید و فایل را حذف کنید.
- به‌طور پیش‌فرض یک «مجتمع نمونه (داده فرضی)» با ۱۲ ماه داده مصنوعی ساخته می‌شود تا نرم‌افزار قابل بررسی باشد.
  برای استقرار واقعی `AQUA_DEMO=0` بگذارید. **داده نمونه کاملاً فرضی است.**

متغیرهای محیطی: `AQUA_DATA_DIR`، `AQUA_DB`، `AQUA_SECRET`، `AQUA_ADMIN_PASSWORD`، `AQUA_DEMO`.

## امکانات

| بخش | توضیح |
|---|---|
| موازنه آب | ΣQin − ΣQout − ΔS = R با عدم قطعیت u_R=√Σu_i² و Z=R/u_R؛ باقیمانده خودکار «نشتی» فرض نمی‌شود؛ جریان بازچرخانی داخلی دوبار شمرده نمی‌شود؛ داده invalid/missing کنار گذاشته و هشدار داده می‌شود |
| KPI | ۱۰ شاخص پیش‌فرض + تعریف شاخص جدید با فرمول (ارزیاب امن AST، بدون `eval`) و حدود هشدار/بحرانی |
| تجهیزات | برج خنک‌کن (E, B, D, M, COC)، صرفه‌جویی افزایش COC، بویلر/کندانس، RO، پمپ، تصفیه‌خانه |
| خط مبنا | رگرسیون چندمتغیره (تولید، دما، ساعات) + صرفه‌جویی تعدیل‌شده با عدم قطعیت و R²/CV(RMSE) |
| ناهنجاری | تشخیص آماری Z-score بر مصرف ماهانه (هشدار، نه اثبات نشتی) |
| بانک راهکارها | ۳۸ راهکار ساختاریافته (مبنای درصد، داده لازم، محدودیت کیفی، روش صحه‌گذاری) + پیشنهاد قاعده‌محور برای هر مجتمع |
| اقتصاد | هزینه واقعی هر m³، بازگشت سرمایه، NPV، IRR، هزینه چرخه عمر، رتبه‌بندی وزنی |
| ورود داده | فرم، CSV (UTF-8/Windows-1256، گزارش خطا به‌تفکیک خط)، سابقه منبع داده |
| امنیت | JWT، گذرواژه PBKDF2، نقش‌ها (مدیر/مهندس/مشاهده‌گر)، لاگ فعالیت، فرار HTML در UI و گزارش |
| گزارش | گزارش HTML قابل چاپ/ذخیره PDF |

## تعاریف مهم (برای تفسیر درست KPIها)

- **مصرف واقعی (consumed)** = ورودی − پساب/بلودان تخلیه‌شده (برداشت، مصرف و تخلیه یکی نیستند).
- **مصرف ویژه آب (SWC)** = مصرف واقعی / تولید؛ **شدت برداشت (FWI)** = آب تازه / تولید.
- **نرخ بازچرخانی** = جریان‌های داخلی (scope=internal) / (ورودی + بازچرخانی).
- **راندمان مصرف** = (ورودی − نشتی − باقیمانده مثبت) / ورودی؛ تعریف «مفید» را متناسب با صنعت بازبینی کنید.
- آستانه ۱۰٪ موازنه فقط **آستانه غربالگری** است (قابل تنظیم برای هر مجتمع).

## محدودیت‌ها و نکات صادقانه

1. **پشته فنی:** در محیط ساخت، نصب FastAPI/SQLAlchemy ممکن نبود؛ بک‌اند با Starlette + sqlite3 ساخته شد. ساختار API و
   جداول با طرح سند سازگار است و انتقال به FastAPI/PostgreSQL مستقیم است. sqlite برای یک سایت و چند کاربر مناسب است؛
   برای چندکارخانه‌ای/همزمانی بالا به PostgreSQL مهاجرت کنید.
2. **اعتبارسنجی مهندسی:** فرمول‌ها با تست‌های مرجع محاسبه‌شده دستی کنترل شده‌اند، اما بانک راهکارها (بازه‌های صرفه‌جویی،
   بازگشت سرمایه) و فرمول تبخیر برج (قاعده سرانگشتی 0.00085×1.8×ΔT×Q) **باید توسط متخصص آب/فرآیند** هر صنعت بازبینی
   و با داده سایت راستی‌آزمایی شوند؛ هیچ عددی ادعای تضمین ندارد.
3. **خارج از دامنه این نسخه:** مدل‌های هوش مصنوعی (پیش‌بینی، خرابی)، Water Pinch/MILP، اتصال PLC/SCADA/OPC UA،
   TimescaleDB، موازنه سطح فرآیند/تجهیز به‌صورت خودکار (موازنه فعلی در سطح سایت است)، API کنترلی. این‌ها فازهای بعدی نقشه راه‌اند.
4. **امنیت استقرار:** پشت HTTPS (reverse proxy) اجرا کنید، `AQUA_SECRET` ثابت و قوی بگذارید، از `data/` پشتیبان بگیرید.
   محدودسازی نرخ تلاش ورود پیاده‌سازی نشده است (در لایه proxy اعمال کنید).
5. فایل Docker در محیط ساخت (بدون Docker) اجرا نشد؛ اجرای محلی (`run.sh`/uvicorn) و تست مرورگر انجام شده است.
